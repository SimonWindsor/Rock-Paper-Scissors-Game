# Rock Paper Scissors ✊🖐✌

A simple interactive Rock-Paper-Scissors game built with JavaScript. The user selects an option and the computer randomly generates its move.

*[Click to play it live](https://simonwindsor.github.io/Rock-Paper-Scissors-Game)*

## Features
- Player vs Computer gameplay
- Randomised computer choices
- Result display for each round
- Simple and responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Open `index.html` in your browser.
